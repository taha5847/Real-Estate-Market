# 🏠 Real Estate Market Analysis | Power BI

## 📊 Project Overview

This project analyzes **100,000 housing transactions** to understand housing prices, property characteristics, geographical trends, and the relationship between housing prices and economic indicators.

The project uses **Power BI** to transform raw housing data into an interactive dashboard that helps identify important patterns and trends in the housing market.

## 🎯 Business Objective

The main objective is to answer questions such as:

- How are housing prices changing over time?
- Which cities and regions have the highest property prices?
- Which property types are most expensive?
- How does property size affect price?
- Which areas have the highest price per square meter?
- How do interest rates and inflation relate to the housing market?
- What is the difference between offer price and final purchase price?

---

## 🗂️ Dataset

The dataset contains **100,000 housing records** and **19 columns**.

| Column | Description |
|---|---|
| `date` | Date of the transaction |
| `quarter` | Quarter of the transaction |
| `house_id` | Unique property identifier |
| `house_type` | Type of property |
| `sales_type` | Type of sale |
| `year_build` | Year the property was built |
| `purchase_price` | Final purchase price |
| `%_change_between_offer_and_purchase` | Change between offer and purchase price |
| `no_rooms` | Number of rooms |
| `sqm` | Property size in square meters |
| `sqm_price` | Price per square meter |
| `city` | City |
| `zip_code` | Postal code |
| `area` | Geographic area |
| `region` | Region |
| `nom_interest_rate%` | Nominal interest rate |
| `dk_ann_infl_rate%` | Annual inflation rate |
| `yield_on_mortgage_credit_bonds%` | Mortgage credit bond yield |
